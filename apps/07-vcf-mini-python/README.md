# 07 - vcf-mini (Python)

[07-vcf-mini-rust](../07-vcf-mini-rust) written in Python. Iterating the open
file yields one line at a time, so a whole-genome call file never has to fit in
memory. [01-hello-python](../01-hello-python) covers what a Python module costs.

## Build and run

```sh
make run APP=07-vcf-mini-python
```
