# 07 - powerhouse-of-the-cell

A full report on the mitochondrial genome, read as one interval. It streams the
`reference` for GC content and density windows, and lists the owner's
`changes` with a text map of where they fall. Like
[06-bitter-meter](../06-bitter-meter), it calls each change from its `carried`
count and the genotype at its first position. It isn't a haplogroup caller, an
ancestry test or a medical report.

## Build and run

```sh
make run APP=07-powerhouse-of-the-cell
```
